# LifeSaver – Blood Donation Management System

**LifeSaver** is a web-based Blood Donation Management System developed to make donor registration, blood requests, and donor searching easier and more organised.

## About the Project

LifeSaver is an academic group project developed as part of the BCA programme. It provides a platform where donors can register, users can search for available donors, and administrators can manage donor records and blood requests.

## Features

- Donor Registration
- Donor Management (CRUD Operations)
- Blood Request Submission
- Blood Request Management
- Donor Search by Blood Group and City
- Admin Login and Dashboard
- Request Status Management
- Responsive website interface

## How to Run the Project

1. Install XAMPP on your computer.
2. Copy the project folder into `C:\xampp\htdocs\`.
3. Start Apache and MySQL from XAMPP Control Panel.
4. Open phpMyAdmin.
5. Create a database named `blood_donation_db`.
6. Set up the required tables: `donors`, `blood_requests`, and `admins`, using the project database structure.
7. Configure the database connection in `config/db.php`.
8. Open your browser and visit:

   `http://localhost/blood_donation_system/`

**Note:** This repository does not currently include a database export file. The database tables must be created separately before running the application.
